# 🌻 گیاهان در برابر زامبی‌ها — بازی

یک بازی برج‌دفاعی کامل و قابل بازی، با الهام از *Plants vs. Zombies*.
تماماً با **HTML5 Canvas + JavaScript خالص** نوشته شده — بدون هیچ کتابخانه، بدون هیچ فایل
تصویری یا صوتی. تمام گرافیک به‌صورت **برداری روی Canvas** کشیده می‌شود و تمام صداها با
**Web Audio API** ساخته می‌شوند.

## اجرا

چون از ماژول‌های ES استفاده می‌شود، باید با یک سرور محلی اجرا شود (نه `file://`):

```bash
cd pvz-game
python3 -m http.server 8080
```

سپس در مرورگر: <http://localhost:8080>

## نحوه بازی

| کار | چطور |
| --- | --- |
| انتخاب بذر | کلیک روی بسته بذر در نوار بالا، یا کلیدهای <kbd>1</kbd>…<kbd>9</kbd> |
| کاشتن | بعد از انتخاب بذر، کلیک روی خانه‌ی خالی چمن |
| جمع کردن آفتاب | کلیک روی گوی‌های زرد |
| برداشتن گیاه | دکمه‌ی بیل یا کلید <kbd>S</kbd> |
| لغو انتخاب | کلیک راست یا <kbd>Esc</kbd> |
| توقف | <kbd>Space</kbd> یا <kbd>Esc</kbd> |

**هدف:** نگذار زامبی از سمت راست به خانه‌ات برسد. هر ردیف یک چمن‌زن اضطراری دارد که
فقط **یک بار** کار می‌کند؛ بعد از آن، عبور زامبی یعنی باخت.

## محتوا

**۹ گیاه:** آفتابگردان · نخودپاش · گردوی دیواری · سیب‌زمینی‌مین · نخود برفی ·
نخودپاش دوقلو · گیاه گوشت‌خوار · بمب گیلاسی · فلفل تند

**۶ زامبی:** ساده · مخروط‌به‌سر · سطل‌به‌سر · پرچم‌دار · روزنامه‌خوان (بعد از از دست دادن
روزنامه دیوانه می‌شود) · فوتبالیست

**۴ حالت بازی:**

| مرحله | توضیح |
| --- | --- |
| ۱ — حیاط جلویی | روز، آموزشی، ۹ موج |
| ۲ — شب در حیاط | شب؛ **آفتاب از آسمان نمی‌بارد** و سنگ‌قبرها جای کاشت را می‌گیرند. ۱۰ موج |
| ۳ — دردسر بزرگ | روز، همه‌ی گیاهان، زامبی فوتبالیست، ۱۰ موج |
| بقا | بی‌پایان با موج‌های فزاینده؛ رکوردت ذخیره می‌شود |

مرحله‌ها با پیشروی باز می‌شوند و پیشرفت در `localStorage` ذخیره می‌شود.

## ساختار کد

```
pvz-game/
├── index.html          رابط کاربری، نوار بالا و صفحه‌های منو
├── styles.css          استایل راست‌چین رابط
├── js/
│   ├── config.js       اعداد تعادل: گیاهان، زامبی‌ها، موج‌ها، مراحل
│   ├── art.js          تمام نقاشی برداری (گیاه، زامبی، پس‌زمینه، افکت)
│   ├── audio.js        موتور صدا با Web Audio (افکت + موسیقی پس‌زمینه)
│   ├── entities.js     کلاس‌های گیاه، زامبی، گلوله، آفتاب، چمن‌زن، ذره
│   ├── game.js         حلقه اصلی، مدیریت موج‌ها، ورودی، رندر
│   └── main.js         اتصال DOM به هسته بازی
└── tests/              تست‌های بی‌مرورگر (Node)
```

همه‌ی اعداد تعادل در یک جا جمع‌اند (`js/config.js`)، پس تغییر سختی بازی ساده است.

## تست

تست‌ها بدون مرورگر و بدون وابستگی خارجی با Node اجرا می‌شوند؛ یک DOM و Canvas
ساختگی جای مرورگر را می‌گیرد تا هم منطق و هم مسیرهای رندر اجرا شوند.

```bash
node pvz-game/tests/smoke.test.mjs     # منطق، رندر، چمن‌زن، شرط برد/باخت
node pvz-game/tests/balance.test.mjs   # یک ربات مرحله‌ها را بازی می‌کند
```

خروجی فعلی تست تعادل (۸ بازی برای هر مرحله):

| مرحله | نرخ برد ربات |
| --- | --- |
| ۱ — حیاط جلویی | ۸/۸ (آموزشی، باید راحت باشد) |
| ۲ — شب در حیاط | ۵/۸ |
| ۳ — دردسر بزرگ | ۳/۸ (معمولاً در موج آخر می‌بازد) |
| بقا | میانگین ~۲۱ موج |

ربات تست استراتژی ساده‌ای دارد، پس یک بازیکن انسان بهتر عمل می‌کند. این اعداد فقط
برای اطمینان از این‌اند که هیچ مرحله‌ای «غیرممکن» یا «بی‌مزه‌ی آسان» نیست.

## نکات فنی

- رندر با توجه به `devicePixelRatio` انجام می‌شود تا روی نمایشگرهای رتینا تیز بماند.
- پس‌زمینه‌ی هر تم یک بار روی بوم جداگانه ساخته و کش می‌شود.
- افکت یخ‌زدگی و فلاش ضربه‌ی زامبی روی یک بوم کمکی و با `source-atop` اعمال می‌شود تا
  فقط پیکسل‌های خود زامبی رنگی شوند.
- کل صحنه با `transform: scale()` به اندازه‌ی پنجره تنظیم می‌شود؛ مختصات ماوس از
  `getBoundingClientRect` محاسبه می‌شود و مستقل از مقیاس درست می‌ماند.
- صدا فقط بعد از اولین تعامل کاربر فعال می‌شود (سیاست autoplay مرورگرها).

# arena-test

یک پروژه ساده برای بررسی صادقانه هوش مصنوعی و ساخت پروژه‌های مختلف با استانداردهای GitHub.

## بخش اصلی پروژه

در این پروژه قرار است این هوش مصنوعی را بررسی کنیم، توانایی‌ها و محدودیت‌هایش را بدون اغراق ثبت کنیم و پروژه‌های مختلف را با استانداردهای GitHub بسازیم.

## فایل‌ها

- `index.html`: صفحه اصلی با ساختار معنایی و بخش `<main>`
- `styles.css`: استایل صفحه اصلی
- `README.md`: معرفی و مستندات پایه پروژه
- `prompts/codm-cp-store-prompt.md`: پرامپت حرفه‌ای ساخت فروشگاه سی‌پی کالاف دیوتی موبایل (نسخه کامل، کوتاه، مرحله‌ای و پرامپت‌های پالیش)

## پرامپت‌ها

پوشه `prompts/` محل نگهداری پرامپت‌های حرفه‌ای است که از یک درخواست ساده به یک بریف فنی کامل تبدیل شده‌اند. هر پرامپت باید:

- بدون ابهام و با ذکر تکنولوژی، صفحات، قواعد کسب‌وکار و معیارهای کیفیت نوشته شود.
- `[PLACEHOLDER]`های قابل تغییر را مشخص کند.
- محدودیت‌ها و نکات حقوقی/امنیتی را صادقانه بیان کند.

## اجرای محلی

برای دیدن صفحه، فایل `index.html` را در مرورگر باز کنید یا یک سرور ساده اجرا کنید:

```bash
python3 -m http.server 8000
```

سپس به آدرس زیر بروید:

```text
http://localhost:8000
```

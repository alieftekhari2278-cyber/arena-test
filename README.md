# زمانا — فروشگاه آنلاین ساعت

یک فروشگاه اینترنتی کامل و راست‌چین (فارسی) برای فروش ساعت مچی، ساخته‌شده با HTML، CSS و JavaScript خالص و بدون هیچ وابستگی یا فریم‌ورک.

## امکانات

- **صفحه اصلی**: بنر هیرو، مزیت‌ها، پرفروش‌ترین‌ها، جدیدترین‌ها، بنرهای کالکشن، شمارش معکوس پیشنهاد ویژه و نظرات مشتریان
- **فروشگاه**: فیلتر دسته‌بندی، برند، بازه قیمت، فقط تخفیف‌دار/موجود، جستجو و مرتب‌سازی (محبوب، جدید، ارزان، گران، امتیاز)
- **صفحه محصول**: گالری تصاویر، مشخصات فنی، انتخاب تعداد، وضعیت موجودی و محصولات مرتبط
- **سبد خرید**: افزودن/حذف، تغییر تعداد، کد تخفیف (`ZAMANA10` و `WATCH5`)، محاسبه ارسال (رایگان بالای ۳۰ میلیون تومان) — ذخیره در `localStorage`
- **تسویه حساب**: فرم اطلاعات گیرنده با اعتبارسنجی، انتخاب روش پرداخت و صفحه تأیید سفارش با کد پیگیری
- **درباره ما**: معرفی، پرسش‌های متداول، گارانتی، ارسال و فرم تماس
- طراحی واکنش‌گرا (موبایل، تبلت، دسکتاپ)، فونت وزیرمتن و قیمت‌ها با اعداد فارسی

> توجه: این یک نسخه نمایشی فرانت‌اند است؛ پرداخت واقعی و بک‌اندی وجود ندارد و داده محصولات در `assets/js/data.js` است.

## ساختار فایل‌ها

```text
index.html        صفحه اصلی
shop.html         لیست محصولات با فیلتر و جستجو
product.html      جزئیات محصول (product.html?id=zn-001)
cart.html         سبد خرید
checkout.html     تسویه حساب
about.html        درباره ما، سوالات متداول و تماس
assets/css/style.css   استایل کامل سایت
assets/js/data.js      داده محصولات و دسته‌بندی‌ها
assets/js/store.js     هدر/فوتر مشترک، سبد خرید و ابزارها
assets/img/            تصاویر محصولات و بنرها
```

## اجرای محلی

```bash
python3 -m http.server 8000
```

سپس در مرورگر باز کنید:

```text
http://localhost:8000
```

## توسعه بعدی (پیشنهادی)

- اتصال به یک بک‌اند واقعی برای محصولات و سفارش‌ها
- حساب کاربری، علاقه‌مندی‌ها و مقایسه محصولات
- درگاه پرداخت واقعی و پنل مدیریت

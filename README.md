# arena-test

یک پروژه ساده برای بررسی صادقانه هوش مصنوعی و ساخت پروژه‌های مختلف با استانداردهای GitHub.

## بخش اصلی پروژه

در این پروژه قرار است این هوش مصنوعی را بررسی کنیم، توانایی‌ها و محدودیت‌هایش را بدون اغراق ثبت کنیم و پروژه‌های مختلف را با استانداردهای GitHub بسازیم.

## 🪰 مغز کامل مگس در یک محیط دوبعدی

بزرگ‌ترین چیزی که تا حالا در این مخزن ساخته شده: کل کانکتوم اسکن‌شدهٔ مغز مگس سرکه
(**۱۳۹٬۲۵۵ نورون، ۱۵٬۰۹۱٬۹۸۳ اتصال، ۵۴٬۴۹۲٬۹۲۲ سیناپس — بدون حذف حتی یک نورون**)
که به‌صورت زنده در یک آرنای دوبعدی راه می‌رود، از موانع دوری می‌کند و غذا می‌خورد.

- **دانلود بستهٔ آمادهٔ اجرا (۶۶ مگابایت):** [`flybrain-complete.zip`](https://github.com/alieftekhari2278-cyber/arena-test/raw/arena/01a0d1cc-arena-test/flybrain-complete.zip)
- راهنمای اجرا: [`RUN.md`](RUN.md) — فقط `numpy` لازم دارد
- گزارش تحقیق عمیق: [`docs/تحقیق-مغز-مگس.md`](docs/تحقیق-مغز-مگس.md)
- مستندات فنی: [`flybrain/README.md`](flybrain/README.md)

## فایل‌ها

- `flybrain/`: موتور شبیه‌سازی، محیط دوبعدی، سرور و رابط کاربری مغز مگس
- `docs/`: گزارش تحقیق دربارهٔ کانکتوم FlyWire و روش‌های وصل‌کردنش به محیط
- `index.html`: صفحه اصلی با ساختار معنایی و بخش `<main>`
- `styles.css`: استایل صفحه اصلی
- `README.md`: معرفی و مستندات پایه پروژه

## اجرای محلی

برای دیدن صفحه، فایل `index.html` را در مرورگر باز کنید یا یک سرور ساده اجرا کنید:

```bash
python3 -m http.server 8000
```

سپس به آدرس زیر بروید:

```text
http://localhost:8000
```

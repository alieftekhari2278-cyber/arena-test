# arena-test — شبیه‌ساز دوبعدی کانکتوم مغز مگس (FlyWire v783)

یک پروژه ساده برای بررسی صادقانه هوش مصنوعی و ساخت پروژه‌های مختلف با استانداردهای GitHub.

این مخزن اکنون شامل یک **شبیه‌ساز حلقه‌بسته** است: نقشه سیم‌کشی واقعی مغز مگس
سرکه (۱۳۹٬۲۵۵ نورون، ۲٬۷۰۰٬۵۱۳ اتصال سیناپسی) به‌صورت یک شبکه اسپایکی
Leaky Integrate-and-Fire اجرا می‌شود و یک عامل را در یک دنیای دوبعدی هدایت می‌کند.

---

## اجرا

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python -m flybrain doctor     # بررسی شبکه، وابستگی‌ها و داده
python -m flybrain fetch      # دانلود ~۱۹۰ مگابایت داده
python -m flybrain build      # ساخت data/build/connectome.npz (~۶ ثانیه)
python -m flybrain validate   # ۷ بررسی بازتولیدپذیر
python -m flybrain serve      # http://localhost:8000
```

هیچ داده‌ای در گیت کامیت نمی‌شود؛ پوشه `data/` در `.gitignore` است.

## داده

| | |
|---|---|
| منبع رسمی | Zenodo [`10.5281/zenodo.10676866`](https://zenodo.org/records/10676866) — CC-BY-4.0 |
| فایل مرجع | `proofread_connections_783.feather` (۸۵۲ مگابایت) |
| نورون‌ها | ۱۳۹٬۲۵۵ نورون proofread |
| اتصالات | ۲٬۷۰۰٬۵۱۳ یال جهت‌دار (آستانه ≥ ۵ سیناپس) |
| کل سیناپس‌ها | ۳۴٬۱۵۳٬۵۶۸ |
| جفت‌های بدون آستانه | ۱۵٬۰۹۱٬۹۸۳ |

**کدام فایل لازم است؟** فایل ۸۵۲ مگابایتی، نه فایل ۹.۵ گیگابایتی.
`proofread_connections_783.feather` خودش تجمیعِ per-pair فایل بزرگ است؛ فایل
۹.۵ گیگابایتی فقط مختصات نانومتری تک‌تک سیناپس‌ها را اضافه می‌کند که این
شبیه‌ساز از آن استفاده نمی‌کند.

**مصرف حافظه** — مشکل اصلی همین بود و حل شد:

| کار | اوج مصرف RAM |
|---|---|
| `pd.read_feather` روی فایل ۹.۵ گیگابایتی | ~۱۲–۱۴ گیگابایت |
| `pd.read_feather` روی فایل ۸۵۲ مگابایتی | ~۲.۵–۳ گیگابایت |
| `python -m flybrain build` | **زیر ۹۰۰ مگابایت** |
| `python -m flybrain serve` | **~۴۰۰ مگابایت** |

سازنده هیچ‌گاه کل جدول را به‌صورت DataFrame در حافظه نمی‌آورد: هر بار یک
row group از parquet را می‌خواند، فقط int32/float32 نگه می‌دارد و با یک
`argsort` + `add.reduceat` تجمیع می‌کند. خروجی یک `.npz` دوازده مگابایتی
(گراف CSR) است که در ۰.۱۵ ثانیه بارگذاری می‌شود.

جزئیات کامل و آینه‌های گیت‌هاب: [`docs/DATA.md`](docs/DATA.md)

## چه چیزی واقعی است و چه چیزی مدل‌سازی

این مهم‌ترین بخش مخزن است. [`docs/MODEL.md`](docs/MODEL.md) مرز را دقیق می‌کشد.

**اندازه‌گیری‌شده (از FlyWire):** توپولوژی کامل، وزن یال = `syn_count`،
نوروترنسمیتر هر نورون (۷۴.۴٪ تحریکی / ۲۵.۶٪ مهاری)، مختصات سه‌بعدی، رده‌های
سلولی — ۱۱٬۳۹۲ فوتورسپتور، ۲٬۲۸۱ نورون بویایی، ۱٬۳۰۳ نورون نزولی.

**انتخاب مدل‌ساز (قابل مناقشه):** مدل LIF با پارامترهای Shiu et al. 2024،
قاعده علامت بر پایه Dale، نگاشت حسی/حرکتی، و مهم‌تر از همه یک **بهره سراسری
سیناپسی** `synaptic_scale = 0.14`.

درباره آن بهره صادق باشیم: با مقدار خام ۱.۰ این مدل کار نمی‌کند. یک انشعاب
دارد و هر ورودی کل مغز را به حالت خوداشتعال ~۸٪ می‌برد که صرف‌نظر از محل تحریک
یکسان است:

```
scale   تحریک چشم چپ            تحریک چشم راست          نتیجه
0.14    optic L 7.6 / R 0.0     optic L 0.0 / R 4.8    ورودی‌محور، جانبی ✓
0.25    DN 47 / 41              DN 47 / 41             سیگنال نابود شد ✗
```

این **به معنای تشنج مغز واقعی مگس نیست** — به معنای نبود سازوکارهای پایدارساز
(هدایت‌پذیری، تأخیر سیناپسی، وفق‌پذیری) در این مدل ساده‌شده است.

## نتایج

خروجی `python -m flybrain validate` — همه اعداد در هر اجرا بازتولید می‌شوند:

```
[PASS] neuron count == 139,255            139,255
[PASS] edges == 2,700,513 (syn>=5)        2,700,513
[PASS] excitatory fraction 70-80%         74.4%
[PASS] left eye -> ipsilateral optic lobe L 7.64 Hz vs R 0.02 Hz
[PASS] descending bias is contralateral   stimL +0.51 Hz, stimR +0.69 Hz
[PASS] gain 0.14 below ignition           27.5 Hz at 0.14 vs 48.2 Hz at 0.25
[PASS] approach separates from avoid      near-source 47% vs 0% (chance 10.4%),
                                          mean dist 226 vs 457
```

دو مورد واقعاً معنادارند، چون **کدنویسی نشده‌اند و از خود سیم‌کشی بیرون می‌آیند**:

1. **رتینوتوپی حفظ می‌شود.** تحریک چشم چپ ۷.۶۴ هرتز در لوب بینایی چپ و
   ۰.۰۲ هرتز در راست تولید می‌کند — نسبت ۳۸۰ برابر.
2. **سوگیری نورون‌های نزولی متقاطع و سازگار است.** چشم چپ → DN راست فعال‌تر؛
   چشم راست → DN چپ فعال‌تر. همین نگاشت ضربدری است که تاکسی را ممکن می‌کند.

رفتار حلقه‌بسته (۴۷٪ در برابر ۰٪ اشغال نزدیک منبع، با سطح شانس ۱۰.۴٪) به
بهره‌های تنظیم‌شده وابسته است و ادعای ضعیف‌تری است.

## این چه چیزی نیست

- **مگس نیست.** بدن، پا، بال و طناب عصبی شکمی ندارد. نورون‌های نزولی اینجا
  صرفاً قطع می‌شوند.
- **پیش‌بینی‌کننده رفتار واقعی نیست.** به هیچ داده رفتاری برازش نشده.
- **کل سیستم عصبی نیست.** FAFB v783 فقط مغز مگس ماده بالغ است.
- **ادعای آگاهی نیست.** یک ماتریس خلوت است و یک آستانه.

# FlyWire 783 — شبیه‌ساز دوبعدی کانکتوم

این مخزن یک شبیه‌ساز دوبعدی برای داده‌های اتصال نورون‌های مغز مگس FlyWire دارد. هدف این نسخه، استفاده از **فایل دقیق و کامل دوم** است:

```text
proofread_connections_783.feather
```

## نتیجه امکان‌سنجی

**بله، از نظر فنی کاملاً شدنی است.** رکورد رسمی Zenodo برای نسخه 783.0 این فایل را با حجم اعلام‌شده 852.0 MB و MD5 زیر منتشر کرده است:

```text
https://zenodo.org/records/10676866
MD5: f48f972d262323a102aed49af1396b8a
```

ساختار فایل برای شبیه‌ساز مناسب است: به‌جای مختصات تک‌تک سیناپس‌ها، هر ردیف اتصال یک جفت نورون، `neuropil`، `syn_count` و میانگین احتمال انتقال‌دهنده‌ها را دارد. بنابراین لازم نیست فایل خام 9.5 GB یعنی `flywire_synapses_783.feather` وارد این برنامه شود.

مخزن اولیه فقط یک صفحه استاتیک داشت و هیچ خواننده Feather یا API نداشت؛ بنابراین اتصال مستقیم فایل به مرورگر به‌تنهایی کافی نبود. برای حل آن، یک سرور محلی سبک اضافه شده است که فقط همسایگی root ID درخواستی را به رابط کاربری می‌فرستد. فایل کامل در git commit نمی‌شود چون یک دیتاست 852 MB است و در `.gitignore` قرار دارد.

> وضعیت این محیط: لینک رسمی با موفقیت شناسایی و checksum تأیید شد، اما دانلود باینری از Zenodo در sandbox فعلی با خطای TLS/SSL قطع شد؛ بنابراین فایل 852 MB را جعل یا به‌صورت ناقص ذخیره نکرده‌ام. downloader قابل‌ادامه آماده است و پس از اجرای آن، رابط به‌صورت خودکار از حالت Demo به Full Feather تغییر می‌کند.

## اجرا با دیتاست کامل

از ریشه پروژه:

```bash
# 1) نصب reader فایل Feather
python3 -m pip install -r requirements.txt

# 2) دریافت فایل کامل رسمی؛ در صورت قطع شدن قابل ادامه است
python3 tools/download_dataset.py

# 3) اجرای شبیه‌ساز
python3 server.py
```

سپس آدرس زیر را باز کن:

```text
http://localhost:8000
```

در محیط preview هم سرور روی `0.0.0.0` گوش می‌دهد و از متغیر محیطی `PORT` پشتیبانی می‌کند.

### بررسی دستی فایل

اسکریپت دانلود پس از پایان، MD5 را بررسی می‌کند. برای بررسی مجدد:

```bash
md5sum data/proofread_connections_783.feather
```

باید این مقدار به‌دست بیاید:

```text
f48f972d262323a102aed49af1396b8a
```

## حالت Demo و Full

- اگر فایل در `data/proofread_connections_783.feather` وجود نداشته باشد، رابط یک گراف نمونه deterministic نمایش می‌دهد و در همه‌جا با `DEMO` برچسب می‌خورد؛ این داده واقعی نیست.
- اگر فایل وجود داشته باشد، `server.py` آن را با `pyarrow` می‌خواند، checksum را در `/api/status` اعلام می‌کند و فقط یال‌های متصل به root ID انتخاب‌شده را به `/api/graph` می‌فرستد.
- شناسه‌های FlyWire به‌صورت رشته به مرورگر می‌روند تا در JavaScript به‌خاطر محدودیت دقت `Number` گرد نشوند.
- کنترل‌های موجود: root ID، حداقل `syn_count`، تعداد یال‌ها، zoom، pan، انتخاب node، نمایش label و حرکت خودکار شبکه.

## فایل‌های اصلی

- `index.html` — رابط فارسی/RTL و داشبورد شبیه‌ساز
- `styles.css` — طراحی تاریک، responsive و canvas viewport
- `app.js` — گراف دوبعدی تعاملی بدون dependency مرورگری
- `server.py` — API محلی برای status و query روی Feather
- `tools/download_dataset.py` — دانلود resumable با MD5 verification
- `data/README.md` — قرارداد نام‌گذاری و محل دیتاست

## API محلی

```text
GET /api/status
GET /api/graph?root=auto&min_synapses=1&limit=50
```

سرور از pandas استفاده نمی‌کند؛ برای خواندن Feather فقط `pyarrow` لازم است. این انتخاب کمک می‌کند فایل خام 9.5 GB هیچ‌وقت وارد محیط شبیه‌ساز نشود.

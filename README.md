# arena-test

یک پروژه ساده برای بررسی صادقانه هوش مصنوعی و ساخت پروژه‌های مختلف با استانداردهای GitHub.

## بخش اصلی پروژه

در این پروژه قرار است این هوش مصنوعی را بررسی کنیم، توانایی‌ها و محدودیت‌هایش را بدون اغراق ثبت کنیم و پروژه‌های مختلف را با استانداردهای GitHub بسازیم.

## فایل‌ها

- `index.html`: صفحه اصلی با ساختار معنایی و بخش `<main>`
- `styles.css`: استایل صفحه اصلی
- `README.md`: معرفی و مستندات پایه پروژه
- `tools/recover-archive/`: ابزار بازیابی آرشیو فیزیک (کتاب درسی + نهایی فیزیک ۳ + کنکور تجربی)
- `docs/بازیابی-آرشیو-فیزیک.md`: نقشه کامل و بازبینی‌شده بازیابی
- `docs/گزارش-اجرا-1405-07-03.md`: گزارش صادقانه اجرا و محدودیت‌های محیط

## بازیابی آرشیو فیزیک

```bash
bash tools/recover-archive/recover.sh --net-check   # تست دسترسی به منابع
bash tools/recover-archive/recover.sh               # بازیابی کامل + راستی‌آزمایی + گزارش
bash tools/recover-archive/selftest.sh              # ۱۶ آزمون آفلاین ابزار
```

## اجرای محلی

برای دیدن صفحه، فایل `index.html` را در مرورگر باز کنید یا یک سرور ساده اجرا کنید:

```bash
python3 -m http.server 8000
```

سپس به آدرس زیر بروید:

```text
http://localhost:8000
```

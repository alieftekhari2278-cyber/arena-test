# arena-test

یک پروژه ساده برای بررسی صادقانه هوش مصنوعی و ساخت پروژه‌های مختلف با استانداردهای GitHub.

## بخش اصلی پروژه

در این پروژه قرار است این هوش مصنوعی را بررسی کنیم، توانایی‌ها و محدودیت‌هایش را بدون اغراق ثبت کنیم و پروژه‌های مختلف را با استانداردهای GitHub بسازیم.

## پروژه‌ها

### 🌻 گیاهان در برابر زامبی‌ها

یک بازی کامل برج‌دفاعی در مرورگر با HTML، CSS و JavaScript خالص — بدون کتابخانه، بدون مرحله‌ی
بیلد و بدون هیچ فایل تصویری یا صوتی خارجی (همه‌ی گرافیک با Canvas و همه‌ی صداها با WebAudio در
زمان اجرا ساخته می‌شوند).

- ۹ گیاه، ۷ نوع زامبی، ۵ مرحله‌ی داستانی + حالت بقای بی‌پایان
- ذخیره‌ی پیشرفت در `localStorage`، رابط فارسی و راست‌به‌چپ، سازگار با موبایل
- تست‌های هدلس در Node با یک DOM/Canvas تقلبی + ربات سنجش بالانس

مسیر: [`game/`](game/) — مستندات کامل: [`game/README.md`](game/README.md)

```bash
npm start        # سرور محلی روی پورت ۸۰۸۰ → http://localhost:8080/game/
npm test         # تست دودی منطق بازی
npm run balance  # گزارش منحنی سختی مراحل
```

## فایل‌ها

- `index.html`: صفحه اصلی با ساختار معنایی و بخش `<main>`
- `styles.css`: استایل صفحه اصلی
- `game/`: بازی «گیاهان در برابر زامبی‌ها»
- `package.json`: اسکریپت‌های اجرا و تست
- `README.md`: معرفی و مستندات پایه پروژه
- `pvz/`: تحقیق درباره بازی «گیاهان در برابر زامبی‌ها» به همراه گالری تصاویر
  ([مستند متنی](pvz/README.md) · [صفحه وب](pvz/index.html))
- `pvz-game/`: بازی کامل و قابل بازیِ «گیاهان در برابر زامبی‌ها» با HTML5 Canvas
  ([راهنما](pvz-game/README.md) · [اجرا](pvz-game/index.html))

## اجرای بازی

```bash
cd pvz-game
python3 -m http.server 8080
```

سپس <http://localhost:8080> را باز کنید. تست‌های بی‌مرورگر:

```bash
node pvz-game/tests/smoke.test.mjs
node pvz-game/tests/balance.test.mjs
```

## اجرای محلی

برای دیدن صفحه، فایل `index.html` را در مرورگر باز کنید یا یک سرور ساده اجرا کنید:

```bash
python3 -m http.server 8000
```

سپس به آدرس زیر بروید:

```text
http://localhost:8000
```

# arena-test

یک پروژه ساده برای بررسی صادقانه هوش مصنوعی و ساخت پروژه‌های مختلف با استانداردهای GitHub.

## بخش اصلی پروژه

در این پروژه قرار است این هوش مصنوعی را بررسی کنیم، توانایی‌ها و محدودیت‌هایش را بدون اغراق ثبت کنیم و پروژه‌های مختلف را با استانداردهای GitHub بسازیم.

## فایل‌ها

- `index.html`: صفحه اصلی با ساختار معنایی و بخش `<main>`
- `styles.css`: استایل صفحه اصلی
- `README.md`: معرفی و مستندات پایه پروژه
- `docs/راهنمای-بازیابی-همه-دانلودها.md`: نقشه کامل بازسازی آرشیو منابع فیزیک کنکور ۱۴۰۶
- `tools/bazyabi/`: پیاده‌سازی خودکار همان راهنما (اسکریپت بازیابی + تست آفلاین)

## ابزار بازیابی آرشیو (`tools/bazyabi`)

بازگرداندن ۹۶ فایل PDF (کتاب‌های درسی، امتحان نهایی فیزیک ۳، کنکور تجربی ۱۴۰۰–۱۴۰۵)
با تلاش مجدد، آینه‌ها، Wayback و راستی‌آزمایی خودکار:

```bash
tools/bazyabi/bazyabi.sh all        # بازیابی کامل
tools/bazyabi/bazyabi.sh verify     # فقط بررسی سلامت آرشیو موجود
bash tools/bazyabi/tests/run_tests.sh   # تست آفلاین (بدون اینترنت)
```

جزئیات در [`tools/bazyabi/README.md`](tools/bazyabi/README.md).
توجه: فایل‌های دانلودشده عمداً در Git ذخیره نمی‌شوند (`download/` در `.gitignore`).

## اجرای محلی

برای دیدن صفحه، فایل `index.html` را در مرورگر باز کنید یا یک سرور ساده اجرا کنید:

```bash
python3 -m http.server 8000
```

سپس به آدرس زیر بروید:

```text
http://localhost:8000
```

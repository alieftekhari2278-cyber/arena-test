# 🔄 بازیابی کامل آرشیو فیزیک — راهنما و اجرا

این پوشه نسخه‌ی اجرایی «راهنمای بازیابی کامل دانلودها» است.
هر agent یا کاربری با همین پوشه می‌تواند کل آرشیو (۹۶ PDF) را بدون جست‌وجوی مجدد بازگرداند.

## اجرا

```bash
bash recover-archive.sh              # همه‌ی مراحل: کتاب‌ها → نهایی → کنکور → راستی‌آزمایی → گزارش
BASE=/masir/delkhah bash recover-archive.sh       # تغییر مسیر مقصد
bash recover-archive.sh books        # فقط کتاب‌های درسی
bash recover-archive.sh nahayi       # فقط امتحان نهایی فیزیک ۳
bash recover-archive.sh konkur       # فقط کنکورهای تجربی
bash recover-archive.sh verify       # فقط راستی‌آزمایی فایل‌های موجود
bash recover-archive.sh report       # فقط گزارش فارسی
```

- مسیر پیش‌فرض: `/home/z/my-project/download`
- پیش‌نیاز اختیاری ولی توصیه‌شده: `apt install poppler-utils` (برای `pdfinfo` و `pdftotext` در مرحله راستی‌آزمایی)
- اسکریپت **idempotent** است: فایل سالم موجود را دوباره دانلود نمی‌کند، پس می‌توان بارها اجرایش کرد تا شکست‌ها جبران شوند.

## E) وقتی دانلود شکست می‌خورد (در اسکریپت پیاده شده)

1. ۳ تلاش با تأخیر پلکانی ۱۰/۲۰/۳۰ ثانیه (خطای 523/429 = فیلترینگ/محدودیت نرخ)
2. آینه `dl.daneshchi.ir/file/chap-school/...` برای کتاب‌ها
3. Wayback: `archive.org/wayback/available` → `web.archive.org/web/{ts}id_/{URL}` (با `id_` بایت خام PDF)
4. دستی: `https://docs.google.com/viewer?url={PDF}` یا جست‌وجوی «{نام کتاب} chapsch.ir pdf»

## F) راستی‌آزمایی (مرحله `verify`)

1. هدر `%PDF-` و حجم > ۵۰KB برای همه فایل‌ها
2. `pdfinfo | Pages` و مقایسه با جدول A
3. کد کتاب روی شناسنامه: `pdftotext -f 2 -l 2 file.pdf - | grep -oE "11[012][0-9]{3}"`
4. سال چاپ بصری: `pdftoppm -f 2 -l 2 -r 150 -png file.pdf out` → دهم ۱۴۰۳، یازدهم ۱۴۰۴، دوازدهم ۱۴۰۵
5. نکته: `pypdf` متن فارسی این PDFها را استخراج نمی‌کند؛ از `pdftotext` یا رندر تصویری استفاده کنید.

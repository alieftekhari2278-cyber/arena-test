# 🌻 گیاهان در برابر زامبی‌ها — نسخه‌ی مرورگری

یک بازی کامل برج‌دفاعی با الهام از *Plants vs. Zombies*، نوشته‌شده با **HTML، CSS و JavaScript خالص**.
بدون هیچ کتابخانه، بدون مرحله‌ی بیلد، و بدون حتی یک فایل تصویری یا صوتی خارجی — تمام گرافیک با
Canvas 2D و همه‌ی افکت‌های صوتی با WebAudio در زمان اجرا تولید می‌شوند.

## اجرا

```bash
# از ریشه‌ی مخزن
python3 -m http.server 8080
# سپس در مرورگر باز کنید:
# http://localhost:8080/game/
```

> چون بازی از ES Modules استفاده می‌کند، باید از طریق یک سرور HTTP باز شود
> (باز کردن مستقیم `file://` توسط مرورگرها بلاک می‌شود).

## نحوه‌ی بازی

| کار | روش |
|---|---|
| انتخاب گیاه | کلیک روی کارت بذر یا کلیدهای `۱` تا `۹` |
| کاشتن | کلیک روی خانه‌ی خالی چمن |
| لغو انتخاب | کلیک راست یا `Esc` |
| برداشتن گیاه | دکمه‌ی بیل یا کلید `S` |
| جمع‌کردن خورشید | کلیک روی خورشید |
| توقف | `Esc` یا دکمه‌ی ⏸ |

هر لاین یک **ماشین چمن‌زنی** دارد که فقط یک‌بار جانتان را نجات می‌دهد؛ اگر زامبی دوباره به خانه برسد، باختید.

## محتوای بازی

**۹ گیاه:** آفتابگردان، نخودپران، گردوی دیواری، مین سیب‌زمینی، نخود یخی، نخودپران دوقلو، بلعنده، بمب گیلاس، فلفل تند.

**۷ زامبی:** ساده، پرچم‌دار، مخروطی، روزنامه‌خوان (بعد از پاره‌شدن روزنامه دیوانه‌وار می‌دود)،
سطلی، فوتبالیست و غول‌پیکر (گیاه را یک‌ضرب له می‌کند).

**۶ مرحله:** پنج مرحله‌ی داستانی با قفل پیشرفت (ذخیره در `localStorage`) به‌علاوه‌ی حالت **بقای بی‌پایان** با ثبت رکورد.

## ساختار کد

```
game/
├── index.html          # اسکلت صفحه و رابط کاربری
├── styles.css          # استایل HUD، منوها و طرح واکنش‌گرا
├── js/
│   ├── config.js       # همه‌ی اعداد بالانس: گیاه، زامبی، مرحله، اقتصاد خورشید
│   ├── entities.js     # کلاس‌های Plant / Zombie / Bullet / Sun / Particle / Mower
│   ├── sprites.js      # کل گرافیک برداری (بدون فایل تصویری)
│   ├── audio.js        # سنتز افکت‌های صوتی با WebAudio
│   └── game.js         # حلقه‌ی بازی، منطق موج‌ها، ورودی و رندر
└── test/
    ├── fake-dom.mjs    # DOM و Canvas تقلبی برای اجرای بازی در Node
    ├── smoke.mjs       # تست دودی: کاشت، شلیک، بیل، انفجار، همه‌ی مراحل
    └── balance.mjs     # ربات خودکار برای سنجش منحنی سختی
```

## تست‌ها

بازی بدون مرورگر و بدون هیچ وابستگی‌ای تست می‌شود؛ یک DOM و Canvas تقلبی ساخته می‌شود و
حلقه‌ی بازی به‌صورت هدلس هزاران فریم اجرا می‌شود.

```bash
npm test        # تست دودی (منطق بازی)
npm run balance # گزارش منحنی سختی
```

خروجی فعلی `npm run balance` (۵ بار بازی خودکار برای هر مرحله، با یک ربات «بازیکن متوسط»
که فقط آفتابگردان/نخودپران می‌کارد و در مواقع اضطراری بمب می‌اندازد):

| مرحله | نرخ برد ربات |
|---|---|
| ۱ — حیاط جلویی | ۱۰۰٪ |
| ۲ — همسایه‌ی مزاحم | ۱۰۰٪ |
| ۳ — شب سطل‌ها | ۶۰٪ |
| ۴ — بازی خانگی | ۴۰٪ |
| ۵ — حمله‌ی نهایی | ۰٪ |

یعنی مراحل پایانی بدون استفاده‌ی درست از گردوی دیواری، نخود یخی و بمب‌ها بُرد نمی‌شوند —
دقیقاً همان چیزی که از یک بازی استراتژیک انتظار می‌رود.

## تصمیم‌های فنی و محدودیت‌ها

- **گرافیک برداری در زمان اجرا:** حجم پروژه بسیار کم می‌ماند و بازی کاملاً آفلاین کار می‌کند،
  اما جزئیات بصری به اندازه‌ی اسپرایت‌شیت‌های دستی نیست.
- **پس‌زمینه‌ی از پیش رندرشده:** چمن شطرنجی یک‌بار در یک canvas جداگانه کشیده می‌شود تا هر فریم بازسازی نشود.
- **مقیاس‌پذیری:** canvas با `devicePixelRatio` (حداکثر ۲٫۵×) رندر می‌شود تا روی نمایشگرهای رتینا تیز بماند.
- **بدون تست مرورگری واقعی:** در این محیط مرورگر هدلس در دسترس نبود، پس تست‌ها روی منطق بازی
  اجرا می‌شوند و مسیر رندر فقط از نظر «خطا ندادن» بررسی می‌شود، نه از نظر درستی بصری.
- **بالانس:** اعداد بر پایه‌ی مقادیر واقعی بازی اصلی (نخودپران ۲۰ آسیب هر ۱٫۴ ثانیه، زامبی ساده ۲۰۰
  جان، مخروطی +۳۷۰، سطلی +۱۱۰۰) تنظیم شده، اما اقتصاد خورشید کمی سخاوتمندانه‌تر است تا هر
  مرحله در حدود ۳ تا ۶ دقیقه تمام شود.
